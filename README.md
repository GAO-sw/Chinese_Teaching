# Веб-страница для практики китайского языка (отправка ответов в один клик)

## Описание
Это статическая веб-страница, предназначенная для онлайн-обучения китайскому языку.
Студент выбирает ответы -> нажимает кнопку -> копирует ссылку -> отправляет учителю.
Учитель открывает ссылку -> ответы автоматически подставляются обратно.

На данный момент это временная версия, сделанная в условиях ограниченного времени.
Вопросы прописаны напрямую в `index.html`.
Каждый раз при добавлении, удалении или изменении вопроса приходится вручную редактировать HTML-код.

В будущем планируется переделать проект на шаблонную структуру:
- Вопросы будут вынесены в отдельную область данных или JSON;
- Вопросы будут автоматически генерироваться с помощью JavaScript;
- При добавлении новых вопросов не нужно будет каждый раз менять `index.html`.

## Файлы
- `index.html`: вопросы, варианты ответов, кнопки
- `style.css`: стили
- `script.js`: генерация ссылки, копирование ссылки, чтение ответов, сброс

## Использование
1. Студент открывает веб-страницу и отвечает на все вопросы.
2. Нажимает кнопку «Скопировать ссылку с моими ответами».
3. Отправляет ссылку учителю.
4. Учитель открывает ссылку, и ответы отображаются автоматически.
